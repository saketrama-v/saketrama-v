## `> cat ./projects`

### [Deepfake Detection System](https://github.com/saketrama-v/BE_FR)
> **Twin-Stream Vision Transformer** that separately analyzes facial and background inconsistencies to detect AI-generated media.

- Built with **ViT-B/16 + MobileNetV3**, **Flask** API, **Next.js** frontend
- Evaluated on DeepfakeTIMIT & Celeb-DF datasets -> **81% combined accuracy**
- Dual-threshold decision logic: strict face check (0.4), background check (0.05)
- `Python` `TensorFlow` `Next.js` `Flask` `Jupyter`

---

### [VoteScale](https://github.com/saketrama-v/VoteScale_DevOps_Learning)
> **End-to-End GitOps CI/CD Pipeline** for a scalable microservices application.

- Infrastructure as Code with **Terraform** to provision clusters
- Continuous Deployment via **ArgoCD** and **Helm** charts for Kubernetes
- Automated workflows and containerization using **GitHub Actions** and **Docker**
- `Docker` `Kubernetes` `Terraform` `ArgoCD` `Helm` `GitHub Actions`

---

### [AgentHub - Cloud IDE with Multi-Agent AI](https://github.com/saketrama-v/AgentHub)
> A fully capable **Human-in-the-Loop Cloud IDE** powered by a hierarchical multi-agent framework to automate complex software engineering tasks end-to-end.

- Built on **CrewAI** - agents plan, write, review, and debug code autonomously
- Human-in-the-loop control lets you supervise, intervene, or redirect at any step
- Designed to handle real engineering workflows, not toy problems
- `Python` `CrewAI` `LLM` `AI Agents` `Cloud IDE`

---

### [BEACON Protocol](https://github.com/saketrama-v/beacon-protocol)
> **Universal Agent SOS Protocol & Receiver Dashboard.** An open-standard escalation layer for AI agents.

- **Real-time WebSocket broadcasting** to a React dashboard for human-in-the-loop decision making
- **Python and Node SDKs** to securely pause LangChain or CrewAI execution threads
- **Multi-Tenant Architecture** backed by Node.js, PostgreSQL, and Prisma
- `Node.js` `React` `Python` `LangChain` `PostgreSQL` `Prisma`
